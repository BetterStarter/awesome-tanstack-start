# Contributing to Awesome TanStack Start

Thank you for your interest in contributing! This is a curated list, so all additions are reviewed for quality and relevance.

## Guidelines

- **Relevance**: Resources must be directly related to TanStack Start (not just TanStack Query or TanStack Router alone, unless the resource meaningfully integrates with TanStack Start).
- **Quality**: Only add high-quality resources. Blog posts and tutorials should be complete, well-written, and accurate.
- **Accessibility**: All resources should be freely accessible without requiring a paid subscription.
- **No duplicates**: Check that the resource is not already listed before submitting.
- **Format**: Follow the existing format for entries:
  ```
  - [Title](URL) – Short description (one sentence).
  ```
- **Placement**: Add the resource to the most appropriate section. If you're unsure, mention it in your pull request description.

## How to Submit

1. Fork this repository.
2. Add your resource to the appropriate section in `README.md`.
3. Open a pull request with a brief description of what you're adding and why it's a valuable addition.

## What is NOT accepted

- Paid resources (courses, books behind paywalls).
- Resources that are outdated or no longer maintained.
- Self-promotion without a genuinely useful resource.
- Generic React or full-stack tutorials that barely mention TanStack Start.
